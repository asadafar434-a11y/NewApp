# Orbital — проектная документация

Orbital — AI-платформа для владельцев бизнеса: поиск специалистов в штат и для точечных
платных консультаций, плюс AI-анализ финансов, маркетинга и операций.

Документация самодостаточна: её должен понять человек или ИИ-агент, не видевший
диалога, в котором она рождалась.

## Как работать по этой документации

1. Открой [10-roadmap.md](10-roadmap.md), найди первую невыполненную задачу в [PROGRESS.md](PROGRESS.md).
2. Открой её файл в `tasks/T-XXX-*.md`, выполни по чек-листу, проверь по «Критериям приёмки».
3. Отметь статус в PROGRESS.md, переходи к следующей.

Зафиксированный стек не обсуждается: pnpm workspaces, React 19 + Vite + TS,
Hono + Node 22, PostgreSQL 16 + Prisma, Better Auth, Docker, GitHub Actions.
