# 10 — Роадмап

Темп: 25 ч/нед, опыт в бэкенде отсутствует → задачи по 2–4 ч, максимально подробные,
каждая оставляет проект в рабочем состоянии. Суммарная оценка ~176 ч ≈ 8–10 недель чистых,
с запасом — **~3 месяца** до прода.

Каждая задача — файл в [tasks/](tasks/); статусы — в [PROGRESS.md](PROGRESS.md).

## Фазы

| Фаза | Результат (проверяемый) |
|---|---|
| **0. Фундамент** | Монорепо pnpm; фронт живёт в `apps/web` и работает как раньше; API отвечает на `/health`; Postgres и MinIO в Docker; CI зелёный |
| **1. Данные** | Prisma-схема целиком, миграции применяются, сиды наполняют БД демо-данными из моков UI |
| **2. Аутентификация** | Сквозной путь: регистрация → письмо → подтверждение → вход → защищённый роут → сброс пароля; фронт на реальном auth |
| **3. Ядро продукта** | Золотой путь целиком: заявка → специалисты (+файлы) → AI-match → чат (SSE + magic-ссылка) → звонок → статусы; NewTask на реальном AI; e2e зелёный |
| **4. Остальные фичи MVP** | Платежи ЮKassa end-to-end; Finance/Marketing/Operations на реальных данных с AI-анализом; Dashboard и уведомления реальные |
| **5. Деплой** | staging и production на VPS работают; CI/CD деплоит; бэкапы крутятся; Sentry ловит |
| **6. Доводка** | e2e на платежи и magic-чат; rate limiting; индексы проверены; прод-чеклист закрыт |

## Критический путь

```
T-001 → T-002 → T-003 → T-007 → T-008 → T-012 → T-013 → T-015/T-016 → T-018 → T-019
→ T-023 → T-025 (чат со специалистом) → T-032 → T-045 → T-046 → T-047 → T-050 → T-053
```

Блокирует всё: **T-001–T-008** (без монорепо, API и схемы не движется ничего) и **T-012–T-016**
(auth нужен каждому эндпоинту). Параллелить можно: Finance/Marketing/Operations (T-036–T-040)
независимы друг от друга и от платежей; деплойные T-044–T-045 можно начинать после фазы 2.
