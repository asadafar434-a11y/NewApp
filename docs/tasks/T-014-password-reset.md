## Критерии приёмки
- [ ] `POST /auth/request-password-reset` пишет ссылку в лог (dev)
- [ ] По ссылке (`POST /auth/reset-password` с токеном) пароль меняется; вход со старым — ошибка
- [ ] Старая сессионная кука после смены пароля → 401

## Как проверить
curl-цепочка: request-reset → URL из лога → reset → sign-in новым паролем → старой кукой /me.

## Подводные камни
Токен сброса одноразовый и с TTL — не кэшировать ссылку в тестах. Ответ request-reset всегда
200 независимо от существования email (не раскрываем базу).
