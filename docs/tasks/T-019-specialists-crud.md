## Подводные камни
`skills` — массив строк: в форме поле «через запятую» с трансформацией (в хуке `useCreateSpecialist`,
как и конвертация цены в T-018). Email специалиста не уникален глобально — уникальность не ставили.

Кнопка «Добавить специалиста» требует выбранной активной заявки (`RequestSelector` из T-018) —
без неё нет `requestId`, кнопка задизейблена с подсказкой «Сначала выберите заявку».

При ручной проверке поиска через curl в Git Bash на Windows кириллица в query-параметрах
без принудительного percent-encoding иногда портится консолью (тот же класс проблемы, что
и с `curl -d` в T-012) — сам поиск на сервере (`mode: 'insensitive'`) работает корректно,
подтверждено и автотестами, и прямым SQL (`ILIKE`) на реальной Postgres-БД.
