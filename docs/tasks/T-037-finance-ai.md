# T-037: Finance — AI-анализ

**Фаза:** 4 · **Оценка:** 3ч · **Зависит от:** T-036, T-028 · **Статус:** todo

## Цель
Кнопка анализа выдаёт реальный список проблем от AI по внесённым данным.

## Контекст
`POST /finance/analyze` → `financeAnalyzeResponseSchema` ([05-api.md](../05-api.md)).
Мок ISSUES и фейковый 2-секундный прогресс удаляются.

## Что сделать
- [ ] `finance.service.ts` analyze: агрегаты за 12 мес + топ категорий → completeJson (схема issues: severity, title, detail, impactKopecks) → сохранить как AiTask kind=finance (история анализов) → вернуть issues
- [ ] Мин. данных: <2 месяцев записей → 400 с сообщением «Добавьте данные хотя бы за 2 месяца»
- [ ] Фронт: query-input Finance запускает analyze (текст запроса — в промпт); лоадер на время вызова; ISSUES → ответ; последний анализ подгружается из истории при заходе
- [ ] Vitest: маловато данных → 400; issues сохраняются (ai замокан)

## Затрагиваемые файлы
- `apps/api/src/services/finance.service.ts`, роут analyze — создать/изменить
- `apps/web/src/pages/Finance.tsx` — изменить

## Критерии приёмки
- [ ] На сидовых данных AI возвращает ≥2 проблем с суммами влияния; отображаются в существующем UI issues
- [ ] Повторный заход показывает последний анализ без нового вызова
- [ ] Лимит токенов действует

## Как проверить
UI: «почему падает прибыль?» → список проблем. Studio: AiTask kind=finance создан.

## Подводные камни
impactKopecks может быть null (не всё измеримо) — UI готов к этому. Промпт просит только
проблемы, выводимые из данных, без выдумок — снижает галлюцинации.
